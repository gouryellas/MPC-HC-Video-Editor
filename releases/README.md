# Release notes

One file per version, from 3.0.1 onwards. These are the notes as they were
published — they are kept as written rather than revised afterwards, so a note
describes the version it shipped with and not the program as it stands today.

The published releases, with the downloadable archive and its checksums, are on
the [releases page](https://github.com/gouryellas/MPC-HC-Video-Editor/releases).
