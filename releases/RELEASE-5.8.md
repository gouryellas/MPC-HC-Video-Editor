# MPC-HC Video Editor 5.8

## Notifications

- Toast notifications have not worked at all, until now. Fixed.
- Operations will indicate their progress, success, or failure with more detail.

## Enter time

- Added a list of examples that show all the different ways you can manually
  add a time or range of times.

## Tags

- Moved to its own menu location.
- Any reference to suffix is now stated as tag.

## Menus

- Greatly improved the organization and cleanliness of the menu items.
- Added headers that follow color themes.
- The edit menu will have a history of actions performed that you can look
  through (up to 20 each way) and click to restore the state of the editor to
  that moment.

## History

- Removing a video via the "Remove" menu item no longer opens that video file.

## Toolbar

- Can be hidden now.

## Bookmarks

- Replaced the radio button for the quick save action with a dynamic small save
  icon.
- Added a step tracker that will show your operation progress. It will
  temporarily show a yellow arrow on the bookmark list. Right now this only
  works if you are using the list view.

## Progress

- The status bar flashes green on success and red on failure for finished
  operations.
- Elapsed time was broken and now works accurately.

## Playlists

- The "Find moved files" operation allows you to select a drive to search
  through. If that fails, there are other search options available that take
  longer and demand more resources.
